# Repository guidance

## M0 scope

Keep this repository's foundation deliberately small. Do not add integrations for
payments, carriers, labels, tracking, or a production database until a later
milestone explicitly requires them.

## Commands

Use pnpm from the repository root:

- `pnpm lint`
- `pnpm format:check`
- `pnpm typecheck`
- `pnpm test`
- `pnpm build`
