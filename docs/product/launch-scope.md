# Launch scope

## M0: Engineering foundation

Included: TypeScript pnpm workspace structure, minimal local web and API apps,
a health check, and quality tooling/CI.

## Phase 1: Product specification and executable domain rules

Included:

- Shipment lifecycle specification and decision records
- Framework-independent transition validation and tests
- Explicit shipment, payment, label, and tracking-event boundaries

Deferred:

- Database schema, migrations, or production database
- Stripe/payment-provider integration or payment collection
- Carrier APIs, label purchasing, tracking webhooks, or event ingestion
- Production infrastructure, credentials, secrets, and background processing
